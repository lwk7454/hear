description: Test newly added code and fix issues
---

Recollect the changes you've made that were untested. Add **ephemeral** tests for the parts that you are not 100% confident with.
Then validate your changed code thoroughly, if issues arose, try fix them then repeat the process.
Remember to clean up after you've done, don't leave unnecessary files in the repo, and especially don't leave test data in dev DB, unless you use a dedicated test DB.
